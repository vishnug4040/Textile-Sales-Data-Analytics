# 🧵 Textile Sales Data Analytics

## 📊 Project Overview

This is an end-to-end **Data Analytics project** focused on analyzing textile shopping and sales data.

The project follows a complete analytics workflow:

**Excel → Python → MySQL → Power BI**

The objective is to transform raw textile sales data into meaningful business insights through data cleaning, database analysis, SQL queries, and interactive Power BI dashboards.

---

## 🎯 Project Objectives

* Analyze textile sales performance.
* Understand customer purchasing patterns.
* Identify top-performing products and categories.
* Analyze revenue and sales trends.
* Evaluate regional and customer-level performance.
* Create interactive dashboards for business decision-making.
* Demonstrate an end-to-end data analytics workflow.

## 🔄 Project Workflow

### 1. Excel – Data Preparation

The raw textile data was organized into separate Excel files/tables.

The data includes information related to areas such as:

* Customers
* Products
* Sales
* Orders
* Categories
* Regions
* Payments
* Inventory

Excel was used as the initial source for organizing and preparing the datasets.

### 2. Python – Data Cleaning & Transformation

Python was used to prepare the data before loading it into the database.

Main activities included:

* Importing Excel files using Pandas
* Checking missing values
* Removing duplicate records
* Handling null values
* Standardizing data formats
* Converting data types
* Performing basic data validation
* Preparing cleaned datasets for MySQL

### 3. MySQL – Database & SQL Analysis

The cleaned datasets were loaded into **MySQL**.

SQL was used to:

* Create database tables
* Define Primary Keys
* Establish Foreign Key relationships
* Validate data
* Join multiple tables
* Analyze sales performance
* Calculate revenue metrics
* Identify top-performing products and customers
* Perform business-oriented SQL analysis

### 4. Power BI – Dashboard & Visualization

The MySQL data was connected to **Power BI** to create an interactive analytical dashboard.

The dashboard focuses on:

* Sales performance
* Revenue analysis
* Product performance
* Customer analysis
* Regional performance
* Sales trends
* Key Performance Indicators (KPIs)

Interactive filters and slicers allow users to explore the data from different perspectives.
